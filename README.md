## SH-MensaCard

Android app that can read the balance from your student card.
It should work for every cafeteria card from the Studentenwerk SH, currently tested with the Campus Card and CAU Card.

## Installation

You can install the app using the latest release: [https://github.com/Ju0x/SH-MensaCard/releases](https://github.com/Ju0x/SH-MensaCard/releases)
